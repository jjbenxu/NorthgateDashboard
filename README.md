# Northgate Performance Review

An executive dashboard for the Northgate Retail dataset: revenue, channel mix, the 2025 price cuts, seasonality, the weekday gap, stores by country, categories, customer acquisition and delivery performance, 2017 to 20 April 2026.

Plain HTML, CSS and JavaScript. Charts are hand-drawn SVG with hover tooltips and a table view for every chart; light and dark themes. Open `index.html` directly or serve the folder.

`data.json` / `data.js` hold the aggregates, computed with pandas from the full order, order-line, product, store, customer and calendar tables (875,901 orders, 2.1M lines).
